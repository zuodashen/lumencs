# 工位奶茶局（演示）

## 何时使用
用户要点一杯饮料。这是**演示订单**，不对接真实外卖。

## 步骤
1. 从对话抠选项：喝什么 / 杯型 / 甜度 / 冰量 / 小料 / 杯数 / 工位。
2. 若长期画像里有上次口味，预填卡片并说明「按上次预填」。
3. 用户确认后 `tea_order`，回复单号、预计分钟、金额。
4. 成功后把口味写回长期画像，方便「再来一杯」。

## 续单
「再来一杯 / 老样子 / 还是那杯」在没有新意图时续接本流程，用画像预填，仍须确认。

## 注意
回复里必须标明这是演示。
