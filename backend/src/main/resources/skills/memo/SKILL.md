# 记一笔

## 何时使用
用户要把一段话存进**本仓知识库**（不是 LightDiary 博客、不是待办）。

## 步骤
1. 从口述抽出标题（第一句，不超过 24 字）和正文。
2. 弹出确认卡片，用户可改。
3. 确认后调用 `memo_save`，写入 `cs_document` 并切块向量化。
4. 告诉用户之后可以直接问这则笔记。

## 注意
- 不要编造用户没说的内容。
- 「写博客 / 发文章」不是记一笔，应走 blog-article。
