# 查行情

## 何时使用
用户要看 A 股（默认）现价、K 线、新闻，或问刚才那只能不能买。

## 步骤
1. 消息里有 6 位代码或名称 → 调盯盘侠搜索/行情。
2. 「这只票 / 可以买吗 / 浮亏补仓还是持有」且没有新代码 → 使用工作记忆里的 `lastStockSymbol`，禁止把整句当搜索词。
3. 成功后写入 lastStock*，用嵌入卡展示报价、迷你 K 线、技术标签。
4. 若盯盘侠已有 TradingAgents 最近一次结果，附在卡片上（只读现成报告，不在聊天里新开 3～5 分钟任务）。
5. K 线多空打分用代码 `KlineScorer`，不要让模型自己算指标。
6. 直接查，不弹确认卡。清流程时不要清 lastStock。

## 回答「能不能买」
用技术面 `actionLabel` 说明，并写明：盯盘侠打分、仅供参考、不是投资建议。想换一只直接说代码或名称。

## 注意
本仓不代下单、不绑交易。未配盯盘侠账号时返回客户端的 blockedReason。
