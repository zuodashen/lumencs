# 知识问答

## 何时使用
用户在问笔记 / 文档里的内容，或关键词没命中任何办事 Skill。这是兜底意图。

## 步骤
1. 可把口语追问改写成独立检索句。
2. 向量 Top8，重排 Top3；向量挂了降级 MySQL 关键词。
3. 严格依据检索片段回答；没有就说知识库里没有，建议上传或「帮我记一下」。
4. 末尾列「引用来源」。带 `articleSlug` 时只搜这一篇。

## 不要做
- 不要编造文档里没有的步骤或数据。
- 「你好」不是知识问答，应走闲聊。
- 写博客 / 加待办走对应办事 Skill。
