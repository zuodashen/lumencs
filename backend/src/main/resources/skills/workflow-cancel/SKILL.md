# 放下未提交卡片

## 何时使用
当前有待确认卡片（写博客、待办、奶茶等），用户不想提交，或改口去干别的。

## 步骤
1. 若话里同时有改稿词（修改 / 润色 / 生活化），**不要取消**，继续原流程改卡片。
2. 否则清工作记忆里的 pending 卡片和槽位（不清 lastStock）。
3. 若去掉取消套话后几乎没剩内容 → 回复：好，先不提交。可以直接说下一件。
4. 若还说了「看待办 / 查行情」等 → 按新意图继续，不要停在取消回复。

## 强切换
未提交时，用户点到**另一个办事意图**（待办、行情、博客列表等）也视为离开当前卡片。
