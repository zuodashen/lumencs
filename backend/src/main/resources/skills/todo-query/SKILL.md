# 查待办

## 何时使用
用户要看清单或某一条进度，而不是新建。

## 步骤
1. 消息里有 `TK-` 编号 → `ticket_query` 查这一条。
2. 否则 `ticket_list` 列出最近若干条（编号、标题、中文状态）。
3. 直接回复列表，不弹确认卡。
4. 空列表时提示可以说「加个待办：…」。

## 注意
状态机不能在查询里改。改状态走 todo-update。
