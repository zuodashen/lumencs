# 改待办状态

## 何时使用
用户要改**已有**待办的状态，通常带 `TK-` 编号。

## 步骤
1. 抽出编号和目标状态（认中文：已创建 / 进行中 / 等待处理 / 已完成 / 已关闭 / 已升级）。
2. 弹出确认卡片，选项只给合法下一跳的提示（代码层仍会校验）。
3. 确认后 `ticket_update`。非法跳步会失败，把允许的下一跳告诉用户。

## 状态机（代码强制，这里只说明）
- 已创建 → 进行中 / 已升级 / 已关闭
- 进行中 → 等待处理 / 已完成 / 已升级
- 等待处理 → 进行中 / 已完成 / 已升级
- 已完成 → 已关闭 / 进行中 / 已升级
- 已升级 → 进行中 / 等待处理 / 已完成
- 已关闭 → 终态，不能再改

**已创建不能直接改成已完成。**
