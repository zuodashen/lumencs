# 已发布博客列表

## 何时使用
用户要看 LightDiary **已经发布**的文章，不是写新草稿。

## 步骤
1. 立刻调 `blog_list`，不弹确认卡。可用很短的关键词过滤；问句（什么时候 / 最近）不要当关键词。
2. 用嵌入卡展示标题，提供「同步」进本仓知识库、「聊这篇」限定 RAG。
3. 未配 `BLOG_BASE_URL` 或列表为空时说明原因。
