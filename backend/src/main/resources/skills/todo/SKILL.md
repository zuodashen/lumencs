# 加待办

## 何时使用
用户要**新记**一件要做的事。

## 步骤
1. 抽出标题（做什么）和可选截止（今天 / 本周 / 以后）。
2. 弹出确认卡片。
3. 确认后 `ticket_create`，编号形如 `TK-日期-后缀`，初始状态「已创建」。
4. 回复里带上编号，方便以后改状态。

## 不要当成加待办
- 「有哪些待办 / 待办列表」→ todo-query
- 「把 TK-… 改成进行中」→ todo-update
