# 安全相关

## 何时使用
用户提到盗刷、欺诈、举报、泄露等。

## 步骤
1. 不要编造已立案、已冻结、保证追回等。
2. 记录诉求，建议走官方渠道，必要时进 HITL。
3. Supervisor 在无其它业务结果时回复：已记录安全相关诉求，建议官方核实并等待人工介入。
